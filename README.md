# Python Calculator

## About the Project
This is a simple calculator developed using Python. It performs basic mathematical calculations based on user input.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- User input
- Conditional statements

## Technologies Used
- Python 3
- Visual Studio Code

## How to Run
1. Install Python.
2. Download this repository.
3. Open the project folder in VS Code.
4. Run `Calculator.py` in the terminal.
